關於本站

這個網站的用途與背後的想法

這個網站是什麼？

本網站是一個家族故事紀錄示範專案。它不只是記錄姓名、年份與事件，而是把一個家庭如何面對困難、如何做選擇、如何留下價值觀的過程保存下來。

未來可以把虛擬人物替換成真實家人，把示範故事改成真正的家族記憶。這個模板的目的，是讓每個家庭都有機會把自己的故事好好說出來、傳下去。

使用技術

  • HTML5
  • CSS3（RWD 響應式設計）
  • JavaScript（原生，無框架）
  • 可直接部署到 GitHub Pages

如何使用這個模板？

編輯 js/data.js 即可新增或修改：

  • 新增故事：在 familyStories 陣列加入一筆物件
  • 新增人物：在 familyPeople 陣列加入一筆物件
  • 更換圖片：將圖片放入 images/ 資料夾，並更新對應 image 欄位路徑

部署到 GitHub Pages

  1. 建立 GitHub repository
  2. 上傳所有檔案
  3. 進入 Settings → Pages
  4. Source 選 main branch，Folder 選 root
  5. 儲存後等待網址產生
